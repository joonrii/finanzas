# Analytics

## Goal
Medir si los usuarios encuentran valor y vuelven a utilizar el producto.

## Acquisition
Eventos/atributos previstos:
- app install / landing visit
- signup
- acquisition source
- campaign
- country
- language

## Activation
- account_created
- first_financial_account_created
- first_transaction_created
- first_5_transactions_created
- onboarding_completed
- csv_imported

## Engagement
- session_started
- transaction_created
- transaction_edited
- transaction_deleted
- analysis_viewed
- dashboard_viewed
- account_viewed
- recurring_created
- csv_imported
- export_created

## Retention
Medir como mínimo:
- D1 retention
- D7 retention
- D30 retention
- weekly active users
- monthly active users

## Monetization
Cuando exista Premium:
- paywall_viewed
- premium_feature_viewed
- trial_started
- subscription_started
- subscription_cancelled
- renewal
- purchase_revenue

## North-star product hypothesis
Una métrica especialmente importante será:

**% de usuarios que siguen registrando movimientos después de 30 días.**

La frecuencia y recurrencia del registro manual será una señal clave de product-market fit inicial.

## Privacy
No recopilar datos financieros innecesarios para analytics.
Separar claramente datos de producto de los datos financieros del usuario.
